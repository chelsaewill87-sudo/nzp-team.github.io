# Assets

**Art direction:** A restrained industrial-survival interface built from charcoal black, desaturated steel, crimson emergency accents, and warm amber action states. The target frame is a sharp first-person corridor scene with readable silhouettes, concrete cover, a shotgun foreground, three approaching enemies, an ammunition pickup, and a compact survival HUD. The remaster shell borrows this language through steel panels, red status indicators, scanlines, hard borders, and amber progress highlights.
